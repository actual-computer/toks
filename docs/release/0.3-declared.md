# toks 0.3: what the release candidate cannot measure

`tools/release/rc_report.py` copies every row of the table below into the release report,
`docs/release/0.3.md`: into its checklist, and into the UNMET table at its top when the status starts
with UNMET or "not run". A row states what was measured or checked, and where. It stays here until a release
meets it. This file is edited by hand; the report never is. A row still "in progress" stops the report until it is
refreshed with what was measured. The gigatoken gate's row is not here: the report computes it from the tree.
